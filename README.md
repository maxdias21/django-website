📰 Django News Website

Projeto desenvolvido durante meus estudos de Django e desenvolvimento web backend.

📌 Sobre o projeto

Este website foi criado com foco em aprender:

Django
Templates
Organização de apps
Internacionalização (i18n)
Estrutura MVC/MVT
Banco de dados
Sistema de notícias/blog

O projeto possui diferentes apps separados para organização da aplicação, além de suporte para tradução em português.

🛠️ Tecnologias utilizadas
Python
Django
HTML
CSS
MySQL
📂 Estrutura do projeto
authors/ → gerenciamento de autores
blog/ → sistema de blog/notícias
news/ → gerenciamento de notícias
locale/ → traduções da aplicação
tests/ → testes do projeto
utils/ → funções auxiliares
website/ → configurações principais
🎯 Objetivo

O principal objetivo deste projeto foi praticar desenvolvimento backend com Django e entender como aplicações maiores podem ser organizadas.

📚 Aprendizados

Durante o desenvolvimento aprendi:

criação de apps no Django,
rotas e views,
templates,
organização de arquivos,
internacionalização,
integração com banco de dados,
e estruturação de projetos backend.

Projeto desenvolvido para fins de estudo e aprendizado 💻
